# SRD draft monster art

This tree contains the visual assets for the independently authored records in
`converted/srd-monsters/doa-monsters.review-required.json`.

- Portraits are original square dark-fantasy bestiary illustrations.
- Tokens are strict overhead PNGs with transparent backgrounds.
- Hex tokens are deterministic `doa-flat-top-hex-v2` derivatives of the tokens.
- `image-manifest.json` records prompts, prompt hashes, asset paths, and coverage.

The records remain `review_required`. Publishing these files to
`https://assets.dungeonsonautomatic.com/monsters/srd-monsters/` makes the asset
bytes available; it does not approve or promote the draft monster mechanics.
